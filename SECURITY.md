# Security Policy

## Reporting Security Issues

The kube-vip maintainers take security seriously. We appreciate your efforts to responsibly disclose your findings.

**Please do not report security vulnerabilities through public GitHub issues.**

Instead, please report them through our [private vulnerability reporting](https://github.com/kube-vip/kube-vip/security/advisories/new) form.

For more details, see the [kube-vip security policy](https://github.com/kube-vip/kube-vip/blob/main/SECURITY.md).
